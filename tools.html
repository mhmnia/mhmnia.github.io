Software and tools

Open tools built around practical research problems: cleaning small-scale InSAR time series and rapidly checking earthquake–volcano proximity.

Peer-reviewed method · Python · GPL-3.0

Common-Mode Filtering for InSAR time series

CMF measures common atmospheric noise from stable pixels around a target and removes it epoch by epoch. It is designed for small volcanic deformation fields where coarse weather-model corrections can struggle.

Earthquake–Volcano Proximity Explorer

Select an earthquake, find nearby Holocene volcanoes, then check satellite radar coverage and possible co-event interferograms before committing to processing.
